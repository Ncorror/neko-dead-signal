# Frontier v1 · модели первой локации

20 самостоятельных GLB, созданных [скриптом проекта](../../../../tools/build_environment_kit.py). Собственный небольшой набор без скачанных моделей, изображений или шрифтов. Происхождение и точные SHA-256, габариты и число треугольников каждого файла — в [manifest.json](manifest.json).

Модули: штаб, генератор, ворота, стена и посадочная площадка; контейнер, корпус транспорта, двигатель и крыло; колонна/балка крана; стела, терминал и каменные детали входа; три скалы и растение с листьями. Единицы — метры, Y вверх, начало внизу по центру. Один mesh и один непрозрачный материал на GLB, цвет в вершинах, без внешних текстур. Размеры вписываются в проверенные габариты 0.0.25.

Из корня репозитория:

```bash
python3 tools/build_environment_kit.py
python3 tools/build_environment_kit.py --check
```

Сборка GLB требует только стандартную библиотеку Python. Дополнительный `--preview` создаёт [контактный лист](../../../../assets/art/environment-frontier-v1/contact_sheet.png) из исходной геометрии; для этого нужны numpy/Pillow. Это техническое превью отдельных моделей, а не снимок игры. Формат — [glTF 2.0](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html).

Ресурсы загружает `surface_assets.gd`; повторяющиеся модели используют общий mesh, растения — MultiMesh. Коллайдеры и расположение заданы отдельно в `surface_environment.gd`, а не автоматически создаются по декоративным деталям.
