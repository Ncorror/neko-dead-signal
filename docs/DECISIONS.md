# NEKO: DEAD SIGNAL — действующие решения

**В силе с 11 ноября 2026.** История обсуждений до смены мира находится в Git, но не служит указанием к реализации. [Единый GDD v0.4](DEAD_SIGNAL_EARTH_GDD_v0.4.md).

## Мир и персонажи
- Земля, 2116 год; 27 лет после Ночи Тишины, начавшейся в 2089-м; загадочный DEAD SIGNAL — основа сюжета.
- **Нет** другой планеты, инопланетных рас, орбитального флота, космического корабля и орбитальных ударов.
- **NEKO** — независимая наземная группа. База «Ночная линия». **КОНТУР** — земная Дирекция карантина. Анклавы — человеческие поселения; Нулевые — автономная земная сеть; Эхо — феномен памяти.
- Первая четвёрка авторских героинь: Амина, Рэйна, Мира Кейд, Лира Восс; Сэйра Нэл и Оралин — земные командиры Контура. Арт, имена и внутренние ID не изменять.
- Будущий пятый танк — взрослый бывший земной контрабандист, не космический пират. Свой аниме-персонаж игрока — проектируемый редактор, не готовая функция.
- Кот Байт находится на базе; необязательный персонаж окружения, не центр мистической причины катастрофы.

## Жанр и управление
- MMORTS / стратегическая MMORPG: наземный открытый мир, обычные данжи без постройки, RTS-суперданжи и еженедельные осады кланов.
- В геройском мире управление по тапу, свободная навигация, изометрическая камера; без обязательного джойстика.
- В RTS игрок командует отрядами и выбранным командиром; сетевые версии позже. Только назначенный лидер клана строит и отдаёт приказы NPC на осадах.
- Существующие мини-карта, рельеф 128×128, туман войны, энергия, производство, навыки, PvE, босс, сохранения и логирование сохраняются.
- Принятые навыки героинь **без изменений**: [баланс v0.3](MMORTS_HERO_SKILL_BALANCE_V03_2026-11-06.md). Мира — хил + боевой дрон, Амина — штурм, Рэйна — поддержка, Лира — снайпер.
- Серверная авторитетность, обработка владельца/видимости/порядка RTS-команд и онлайн-матч — ещё не реализованы.

## Инженерные ограничения совместимости
- Не менять Android package ID, текущие `user://` пути сохранений и внутренние индексы сторон `0` (NEKO) / `1` (КОНТУР). Ранее индекс 1 означал «Саари»; новая земная интерпретация только визуальная и сюжетная.
- `scripts/test_pure_rts_contract.py`, `scripts/verify-layout.sh`, UI тесты и README обновляются вместе с каноном: старые проверки инопланетных рас не восстанавливать.
- Лира: два оригинальных GLB, 66 костей/20 клипов, работа Blender в отдельной ветке до визуального PASS двухручного хвата. Не подменять отсутствующий Rifle_Fire клип стрельбой из лука.
- Не переименовывать рабочие VPS-сервисы, GitHub runners, системные каталоги и старые диагностические артефакты без плана миграции.
- Новые версии проверять через Python/структурные/Godot/Android CI и физическое устройство; выполнение CI не доказывает художественное качество или игровой онлайн.
