# Лира Восс — сохранённый план снайперских анимаций Meshy v1

**Дата фиксации:** 2026-11-04. **Статус:** кандидатный список клипов для будущего риггинга, НЕ экспортированные анимации и НЕ реализованная механика.

## Утверждено по геймдизайну

- Роль Лиры — **снайпер-разведчик**. Основное оружие — **длинная снайперская винтовка**, а не штурмовой автомат.
- Дальность с учётом правки **+2**: **16 единиц** обычно, **18** после подготовки неподвижной позиции.
- Сильный одиночный выстрел, прицеливание перед атакой, низкая скорострельность, слабость вблизи.
- Движение или потеря прямой видимости цели отменяют прицеливание. Вести точный огонь на бегу нельзя.
- Только RTS-управление: выделить Лиру и отдать приказ; нет ручного управления от третьего лица.
- Игровой сервер в будущем решает попадания, тайминг и урон. AnimationPlayer/AnimationTree только визуализируют событие.
- Полная спецификация: [LYRA_VOSS_SNIPER_COMBAT_DESIGN_v1.md](LYRA_VOSS_SNIPER_COMBAT_DESIGN_v1.md).

## Кандидаты из библиотеки Meshy

Это **названия/идентификаторы для поиска**, собранные на стадии исследования. Наличие в каталоге НЕ означает, что пресет открыт в текущем тарифе, корректно переносится на наш риг или идеально соответствует длинной снайперской винтовке. Перед расходованием кредитов заново сверять название, ID, превью и условия конкретного аккаунта.

| Движение | Meshy motion, кандидат | Action ID / статус | Применение |
|---|---|---|---|
| Ожидание | `Idle` | 0 | Цикл в покое |
| Ходьба | `Walking_Woman` | 1 | Приказ движения |
| Скрытная ходьба | `Sneaky_Walk` | 559 | Разведка / обход |
| Разворот с винтовкой | `Rifle_Turn_Left` | 573, сверить | Поворот корпуса к цели |
| Разворот при прицеливании | `Rifle_Aim_Turn_Right` | **585**, подтверждено в официальном Meshy Animation Library 2026-11-04 | Поворот с оптикой; проверить удержание длинной винтовки |
| Перезарядка стоя | `Standing_Reload` | 170 | Стойка |
| Перезарядка с колена | `Kneeling_Reload` | 165 | Дополнительная стойка |
| Перезарядка лёжа | `Prone_Reload` | 168 | Только если будет лёжа |
| Приседание и подбор оружия | `Female_Crouch_Pick_Gun_Point_Forward` | 279, сверить | Возможный переход |
| Универсальная атака | `Attack` | 4 | **Только временный кандидат**: не гарантирует снайперский хват |
| Реакция на попадание | `Hit_Reaction` | 178 | Короткий hit |
| Смерть | `Dead` | 8 | Терминальное состояние |

Каталог и примеры: [Meshy Animation Library](https://docs.meshy.ai/en/api/animation-library), [Rifle Aim Turn Right](https://www.meshy.ai/animation-library/walk-and-run/turning-around/rifle-aim-turn-right), [Kneeling Reload](https://www.meshy.ai/animation-library/fighting/transitioning/kneeling-reload), [Prone Reload](https://www.meshy.ai/animation-library/fighting/transitioning/prone-reload).

**Стоимость/доступ:** ранее некоторые винтовочные и reload-пресеты были отмечены как возможные Pro-анимации; **не считать это проверенным тарифным фактом для нашего аккаунта**. Проверить непосредственно в Meshy перед генерацией. Text-to-Motion может быть вариантом для отсутствующего клипа, но также требует предварительной проверки тарифа и качества результата.

## Рекомендуемый минимальный пакет для первого Android-теста

1. `Idle` с удержанием длинной винтовки.
2. `Walk` с оружием опущенным, по желанию `Sneaky_Walk`.
3. Стойка прицеливания (переход) и удержание прицела **через оптику**.
4. Одиночный выстрел с отдачей и возвратом в прицеливание.
5. `Standing_Reload` или адаптированный rifle reload.
6. `Hit_Reaction` + `Dead`.

**Необходимы собственные доработки/проверки**: корректный упор приклада в плечо, правая рука на рукояти, левая на цевье, голова у оптики, отсутствие пересечений куртки/ремней/волос. Адаптация через Godot `AnimationTree`, Skeleton3D, отдельный attachment винтовки, при необходимости additive pose/IK. Для снайперского прицеливания и отдачи использовать специализированный клип или авторскую анимацию — `Attack` не гарантирует нужную механику.

Позже: колено и огонь с колена, позиции лёжа, разведдрон, Overwatch, маркировка цели. **Не оплачивать эти клипы до появления корректно работающей базовой модели.**

- Для single-image Image-to-3D использовать **одну фронтальную A-позу**, а не коллаж/четыре фигуры. Фон рекомендуется светлый однородный с хорошо читаемыми краями тёмного костюма. Оригиналы не менять.
- Отдельные версии GLB: неанимированная сетка → `Skeleton3D`/Humanoid Rig → клипы → Godot → физический Android-тест.

## Критерии перед отметкой «готово»

- В итоговом GLB есть rig/skin и требуемые animation clips; не полагаться на слово «Animated» в интерфейсе.
- Анимации воспроизводятся в Godot на конкретной модели Лиры, руки удерживают винтовку, нет сломанных суставов.
- Перемещение и повороты не требуют root-motion вмешательства в игровую логику.
- Бой соблюдает дальность 16/18, прямую видимость и время прицеливания **после отдельной кодовой реализации**, которая пока не выполнена.
- FPS и память проверены на реальном Android; UI остаётся RTS, без джойстика.

**Текущий статус проекта:** документация сохранена в GitHub, готовый rigged GLB и снайперские клипы Лиры ещё не импортированы. Настоящая дальность и снайперская логика ещё не внесены в игровой код. Это отложенный этап без оплаты/автоматического запуска.
