## Техническая приёмка / ограничения

1. **Это четыре отдельные художественные генерации**, а не четыре математически точных вида одной 3D-сетки. Проверить толщину торса, положение рук, симметрию двух заколок, рисунки на одежде, ноги и масштаб. Для точности использовать Multi-View по главному 01_FRONT; визуальный канон v3 при этом не менять.
2. Любой Image-to-3D выход (Meshy/Tripo) — **новый кандидат**, сравнивать с v3 в одинаковой фронтальной, боковой и задней камере. Не признавать мастер-модель на основании красивого одного скриншота.
3. Master-ассет: визуально качественное лицо и волосы; после создания сохранить оригинал, источник генерации, используемую лицензию, отдельную текстуру/GLB/FBX.
4. Для игрового клиента: производная **чистая, ригованная, лёгкая модель** и набор LOD. НЕ запускать 470k треугольников / около миллиона вершин на десятках игроков без оптимизации. Точные бюджеты — только по измерениям FPS/frametime/памяти на Android.
5. Персонажи игроков: одна базовая совместимая система скелета на тип тела, отдельные волосы/ботинки/броня, совместимое положение костей. Нейросети не гарантируют удобную для изменения лица топологию/blend-shapes или общий риг для всех костюмов.
6. Существующие сцены RTS/Android-клиента и локальные сохранения **не изменены**. Эта документация не означает, что 3D персонаж импортирован или анимирован.
