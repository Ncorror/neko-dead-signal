# Рэйна — «Тактический барьер»: СТЕНА / КУПОЛ · design v0.1 (ОТМЕНЕНО)

> **УСТАРЕВШАЯ КОНЦЕПЦИЯ — НЕ РЕАЛИЗОВЫВАТЬ.** По последнему решению пользователя (2026-11-06) Рэйна больше не ставит стену/купол и не переключает режимы. Она **накладывает целевой защитный щит на выбранного союзника**, как Мира выбирает цель лечения. Актуальная спецификация: [REINA_TARGETED_SHIELD_DESIGN_v0.1.md](REINA_TARGETED_SHIELD_DESIGN_v0.1.md). Исторический материал ниже сохранён только для объяснения эволюции дизайна.

**Дата:** 2026-11-06. **Статус:** пользователь **утвердил два режима одной способности**: «СТЕНА» и «КУПОЛ». Управление, конкретные защитные правила, численный баланс и статус класса Support **пока предмет обсуждения**. Это проектный документ, **не код и не испытанная механика**.

## 1. Неизменяемое утверждённое решение

- Один персонаж: `reina` (Рэйна); способность «Тактический барьер».
- У этой способности **два выбираемых режима — направленная стена и круговой купол**. Это не две отдельные способности и не два одновременно доступных экземпляра.
- Остальные способности Рэйны, точные характеристики и её окончательное назначение в класс Support ещё не утверждены отдельно.
- Барьер — личная способность героя. В MMO-суперданже или еженедельной осаде использование барьера **не предоставляет право строить/управлять NPC-войсками**: стратегические права остаются только у лидера стороны.

## 2. Предложенная дифференциация режимов — подлежит утверждению

| Параметр | СТЕНА | КУПОЛ |
| --- | --- | --- |
| Геометрия | Направленная вертикальная энергетическая поверхность, поворачиваемая при установке | Неподвижная полусфера вокруг выбранной точки |
| Назначение | Укрыть направление наступления и дать вести огонь | Экстренно защитить группу на месте, позволить лечить/воскрешать |
| Входящий вражеский огонь | Перехватывает с защищаемой стороны, не страхует тыл и фланги | Перехватывает с разных направлений |
| Исходящий огонь | Союзникам разрешён выстрел сквозь стену наружу, по правилам владельца | **Предложение:** блокируется в обе стороны; режим временной защиты, а не неуязвимая огневая точка |
| Движение | Союзные персонажи могут проходить насквозь | Союзные персонажи могут входить и выходить |
| Прочность | Относительно высокая | Ниже стены |
| Мобильность | После установки неподвижна | После установки неподвижен |

**Вопрос на обсуждение:** стрелять изнутри купола наружу нельзя по предложенному варианту, но это ещё не утверждено. Уточнить взаимодействие не только с пулями, но и с гранатами, артиллерией, лучами, AoE снарядами, умениями и лечением. Не давать барьеру блокировать всё без проверки пересечения траектории и разрешённых типов урона.

## 3. Стартовые числа для тестов (НЕ утверждены)

| Параметр | СТЕНА | КУПОЛ |
| --- | --- | --- |
| Время жизни | 10 секунд | 7 секунд |
| Прочность | 100% условной базовой прочности щита | 70% от базовой прочности стены |
| Общий cooldown | 50 секунд | 50 секунд |
| Одновременно у одного героя | Максимум один общий барьер | Максимум один общий барьер |

- **Предложение по состояниям:** `ready -> targeting -> active -> cooldown -> ready`. Общий cooldown для обоих режимов, а не независимые откаты. Переключение режима до подтверждённой установки бесплатно, после установки — не позволяет развернуть вторую форму.
- На время cooldown **другой режим тоже недоступен**.
- Нельзя разворачивать два барьера одновременно, сохранять барьеры переключением режимов либо обходить cooldown переподключением, переходом между сценами или повторным касанием.
- Точные значения прочности в единицах HP зависят от реальной боевой формулы игры; 100%/70% — относительное сравнение, не утверждённые игровые HP.
- Продолжительность и cooldown балансировать раздельно для PvE/суперданжей/PvP, не изменяя фундаментальные правила двух режимов без согласования.
- Параметры размещения, расстояние до точки установки, энергия/стоимость, размер купола, длина стены и высота покрытия остаются открытыми.

## 4. Управление на Android — предложенный UX

**Одна кнопка «Тактический барьер» и переключение режимов внутри одной способности**. Не занимать две постоянные ячейки активных умений.

1. Нажать значок барьера — откроется компактный выбор «СТЕНА / КУПОЛ»; последний режим можно запоминать. Пока это `targeting`, не применённый навык.
2. Для стены: касание точки установки показывает полупрозрачную предварительную стену; короткое перетаскивание/ручка поворота задаёт ориентацию. Для купола: точка задаёт центр полусферы; отдельного поворота нет.
3. Показать прозрачный контур, границы, допустимость размещения, союзников в зоне, цену, cooldown. Невалидная точка — красная/контрастная подсказка, без расходования ресурса.
4. Отдельное **«Установить»** подтверждает активацию; **«Отмена»** или повторное нажатие снимает предпросмотр без движения героя и без траты ресурса. Для быстрого купола вокруг себя можно добавить отдельный жест/двойное нажатие **только после проверки ложных срабатываний на Android**.
5. Смена режима при предпросмотре не расходует ресурс и не запускает cooldown. При активном щите нельзя бесплатно преобразовать стену в купол.
6. Свайпы камеры, мультитач, выбор персонажей и миникарта не превращаются в команды передвижения. Контролы не перекрывают боевую сцену и маленькие экраны.

Это предварительное поведение UI, не уже реализованный контроллер.

## 5. Симуляция, баланс и проверки

- Сервер авторитетно решает: владелец способности, координаты и коллизии, стоимость, допустимое расстояние/LOS, доступность, таймер, прочность, типы снарядов, принадлежность команды и уничтожение.
- Обе формы способны разрушиться **раньше срока** после исчерпания прочности. В PvP обязательны способы противодействия: обход стены, уничтожение генератора/барьера разрешённым уроном, ожидание исчезновения, координация атак.
- Визуальный полупрозрачный барьер не означает неуязвимость; урон и столкновения рассчитываются по физическому препятствию, а не по одному VFX.
- Одновременно несколько игроков-Рэйн: требуется правило лимитов/суммирования защитных полей на площади, чтобы не получить бесконечный коридор бессмертия.
- Герои и NPC-войска в RTS-инстансе могут получать прикрытие от барьера, но способность не влияет на экономику, строительство и разрешения командира.
- Проверить: фронтальная/фланговая траектория у стены, вход/выход через купол, выстрелы наружу, AoE-эффекты, прерванная установка, смерть/респаун, таймер и обнуление после reconnect, одновременные заклинания, работу лечения Миры внутри купола и гранат Амины снаружи.
- При столкновении с пассивкой Миры «Защитный контур» не дублировать личный эффект щита; математику суммирования снижения урона утвердить отдельно.

## 6. Статус изменений

- **Утверждено сейчас:** у Рэйны один «Тактический барьер» с двумя режимами, **СТЕНА + КУПОЛ**.
- **Предложено, не подтверждено:** сквозная союзная стрельба через стену, двусторонняя блокировка купола, численные значения 10/7 секунд, 100/70% прочности, 50 секунд общего cooldown, один одновременно активный барьер, UX-последовательность.
- **Не реализовано / не протестировано:** состояние навыка в Godot, сервер, VFX, Android UI, баланс PvE/PvP.
