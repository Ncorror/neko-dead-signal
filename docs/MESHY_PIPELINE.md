# NEKO: DEAD SIGNAL · Meshy Pro → Godot → Android (MMORTS)

**Состояние 2026-11-09:** пользователь подтвердил активную подписку Meshy Pro. Используем её как основной производственный путь. Экспорт новой 3D female_base_v3, риг и игровые анимации ещё не подтверждены. При экспорте отдельно проверяем лицензионные права и оптимизацию под Android. [Контракт](NEKO_REBRAND_028_2026-11-09.md).

Оригиналы никогда не перезаписывать. Рабочий цикл: **2D-портрет → отдельная одиночная A/T-pose → Image to 3D → Remesh (при необходимости) → UV/текстуры → Humanoid Rig → Idle/Walk/Run → дополнительные клипы → GLB → Godot/Android**.

1. Персонаж для меню и командир как 3D-юнит — два различных вида ассетов. Не подменять высокодетальный портрет тяжеленной моделью в RTS.
2. Для Meshy загружаем **одну фигуру** на чистом фоне; turnaround из 4 ракурсов — для multi-image/reference, не single-image генерация.
3. Оставить канон: милые взрослые аниме-героини с узнаваемыми лицами, кошачьими мотивами, лёгкой футуристической одеждой и минимумом тяжёлых полигональных аксессуаров.
4. Ориентир LOD0 для героини 12–15 тыс. треугольников, LOD1 5–7 тыс., LOD2 1,5–3 тыс. Тестовые, не жёсткие цифры; массовые солдаты проще. Следить за draw calls, количеством костей, материалов и overdraw от волос.
5. На этапе первой 3D-версии использовать **Humanoid Rig**, не Smart Rig; сначала протестировать Idle (0), Walk (1), Run (14). Затем Attack (4), Hit (178), Dead (8).
6. Упростить анимации для RTS: физическое перемещение юнита задаёт логика/сервер; клип должен быть на месте (in-place) либо root motion корректируется.
7. Экспортировать GLB с движениями; импортировать как отдельный ресурс, затем управлять `AnimationPlayer + AnimationTree` и StateMachine, не переписыванием root transforms из клипа.
8. В Godot и на телефоне проверить пересечения юбки с ногами, наушники/уши, хвостики, стопы, масштаб и FPS при 1/10/30/50 юнитах. Число 50 — тест, не гарантированная производительность.
9. Неполучившийся риг не лечить покупкой десятка новых клипов — сначала исправить модель/топологию.
10. Лицензии и дата генерации фиксируются для каждой версии; не добавлять чужие референсы в публичные игровые файлы без прав.

Полная матрица и **точные action_id из официальной библиотеки**: [ANIMATION_REQUIREMENTS_RTS.md](ANIMATION_REQUIREMENTS_RTS.md).

Официальный порядок Meshy: https://docs.meshy.ai/en/webapp/guides/choosing/post-processing ; риг: https://docs.meshy.ai/en/webapp/guides/3d-model/rigging ; Godot: https://docs.godotengine.org/en/stable/tutorials/animation/animation_tree.html.
