# NEKO: DEAD SIGNAL — дорожная карта Земли

**Точка:** ноябрь 2026, действующая новая сюжетная ветка pre-alpha 0.0.33, Godot 4.7.2. Прежняя космическая дорожная карта отменена. [Сюжет и система — GDD v0.4](DEAD_SIGNAL_EARTH_GDD_v0.4.md). Внутренние пути и сохранения сохраняются.

## Сделано и подтверждено по прежним сборкам

- [x] Android-основа и CI, интерфейс выбора героини, её индекс и сохранение выбора.
- [x] Локальная RTS: приказы, отряды, туман войны, навигация, строительство, энергия и производство.
- [x] Сектор 01 · 128×128, пять точек, рельеф, управление тапами и сохранение маршрутов.
- [x] PvE «Ржавый тракт»: восемь мобов и Страж узла; локальная экономика наград.
- [x] Героини и принятые классы; у Лиры исходная модель, риг и лаборатория анимации. Отдельные Blender-драфты пока не приняты.
- [x] Отдельный сериализуемый RTS-order DTO и headless тесты. Это не сеть, серверный матч ещё отсутствует.
- [x] **11 ноября 2026:** новый сюжет Земли после Ночи Тишины зафиксирован в v0.4, код меню и сценарные строки переосмыслены без перенумерации данных. Отменённые космические GDD удалены из дерева, история Git сохранена.

## Ближайшая цепочка

1. [ ] **Земная редакция:** завершить замену экранных космических надписей, привести в соответствие проверки и документацию; убрать из рабочего дерева прежние сюжетные GDD; CI Python/Godot/Android. Физический Android-прогон только после проверки сборки.
2. [ ] **Атмосфера первой локации:** дорога, обесточенный город, ржавый транспорт, разросшаяся растительность, радиоаномалии; оставить существующие коллайдеры и навигацию. Фоновый город вместо орбиты.
3. [ ] **Лира Восс — Gold Standard:** исправить реальную геометрию хвата и ориентацию пальцев/локтей; 4 ракурса, кадры отдачи, Blender CI, только затем GLB в Godot. Другая ветка `agent/neko32-gpt` не должна терять историю/Blender-артефакты.
4. [ ] **Сюжетная цепочка 1 акта:** Вега → три маяка → голос сестры Лиры → Ржавый тракт → Страж узла → Подстанция 17. Имена и тексты меняются постепенно, а игровой прогресс/награды сохраняются.
5. [ ] **Другие героини:** готовые риги и авторские движения для Амины/Рэйны/Миры после визуального стандарта Лиры; нет фиктивного «готово».
6. [ ] **Серверный RTS:** подтверждение владельца `actor_id`, видимости и `sequence`; адаптер к существующим приказам. Ни полноценной MMO, ни сетевой синхронизации пока нет.
7. [ ] **Город и данж:** земная локация с безопасным хабом, торговлей, заданиями и первым обычным данжем; не подменять обычный данж RTS.
8. [ ] **Онлайн-мир и кланы:** авторитетные серверные состояния, инстансы, безопасное переподключение, территория и недельные осады. Измерить нагрузку на VPS прежде чем обещать массовые бои.

## Релизные правила

- Версия в `client/project.godot` — фактическая, а не число из старого документа.
- Не стирать старые рабочие функции, ассеты, проделанные тесты, логи, сохранения и CI ради сюжета.
- Папки удалённых космических GDD в Git-истории остаются доступны только как история, а не как план; исходное место решения больше не должно вести в прошлый космический сеттинг.
- Сохранять единый журнал в `docs/ROADMAP.md`, не заводить параллельных аудит-документов.
