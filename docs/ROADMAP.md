# NEKO: DEAD SIGNAL — дорожная карта Земли

**Точка:** ноябрь 2026, pre-alpha 0.0.33, Godot 4.7.2. Единственный действующий мир — Земля после Ночи Тишины. Канон: [GDD v0.4](DEAD_SIGNAL_EARTH_GDD_v0.4.md).

## Готово и сохранено

- [x] Android-основа и CI; выбор героини и стабильные внутренние ID.
- [x] Локальная RTS: приказы, отряды, туман войны, навигация, строительство, энергия, производство и поражение.
- [x] Земной сектор 01 · 128×128: пять точек, рельеф, управление тапами и сохранение маршрутов.
- [x] PvE «Ржавый тракт»: восемь противников, Страж узла и одноразовая награда.
- [x] Земной канон 2116: NEKO / КОНТУР, база «Ночная линия», Нулевые, Эхо, Анклавы.
- [x] Лира: исходный GLB, 20 клипов, винтовка, Animation Lab и сохранённые регрессии покадрового просмотра, смерти, разворота к цели и смены агрессора.
- [x] Старые космические GDD и промежуточные планы удалены из рабочего дерева; история остаётся только в Git.
- [x] RTS-order DTO и headless-тесты. Это пока не сетевой матч и не готовая MMO.

## Ближайшая цепочка

1. [ ] **Атмосфера первой локации:** холодный смог, обесточенный город, ржавый транспорт, дорожные остатки, разросшаяся земная растительность и радиоаномалия DEAD SIGNAL. Коллайдеры, навигация и сохранения не менять.
2. [ ] **Лира Восс — Gold Standard:** реальная геометрия двухручного хвата, пальцы/локти, 4 ракурса и кадры отдачи. Blender-драфт не становится игровым ассетом без визуального PASS.
3. [ ] **Сюжетная цепочка I акта:** Вега → три маяка → голос сестры Лиры → Ржавый тракт → Страж узла → Подстанция 17.
4. [ ] **Другие героини:** готовые риги и авторские движения для Амины, Рэйны и Миры после утверждения стандарта Лиры.
5. [ ] **Серверный RTS:** проверка owner/actor_id, видимости и sequence поверх существующего DTO.
6. [ ] **Город и обычный данж:** безопасный хаб, торговля, задания и первый данж без RTS-строительства.
7. [ ] **Онлайн-мир и кланы:** авторитетные серверные состояния, инстансы, переподключение, территория и недельные осады после нагрузочного теста VPS.

## Релизные правила

- Версия берётся из `client/project.godot`, а не из старых отчётов.
- Рабочие функции, сохранения, тесты и исходные ассеты не удалять ради сюжетной чистки.
- Старые ветки и документы не являются источником требований. После переноса уникальных исправлений их содержимое не восстанавливать.
- Единственный журнал статуса — этот `docs/ROADMAP.md`; параллельные аудит-документы не создавать.
