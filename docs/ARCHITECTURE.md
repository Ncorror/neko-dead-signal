# REINA: DEAD SIGNAL RTS — техническая архитектура v0.1

**Статус:** проектный план, сервер и боевые системы ещё не реализованы.

## Клиент
Godot 4.x на Android. Изометрическая камера, 3D-модели GLB, анимации, интерфейс RTS, ввод для управления героиней и приказы отрядам. Клиент не является источником истины для экономики и результатов боя.

## Сервер сражений
Авторитетная симуляция передвижения, производства, юнитов, подбора контейнеров, тумана войны и боевых событий. Сетевой протокол с порядковыми номерами команд; переподключение к сохранённому серверному состоянию.

## Постоянный мир
Сервис аккаунтов, рас, кораблей, героев, технологий, флотилий и территорий. PostgreSQL для постоянных данных, идемпотентная обработка наград.

## Инварианты
1. Выбранный на корабле офицер появляется в начале высадки без казарм и исследований.
2. Переключение RTS/героиня не останавливает производство и бой.
3. Скрытые контейнеры и противники не передаются клиенту, пока не обнаружены.
4. Каждый контейнер выдаёт награду только один раз; все начисления подтверждает сервер.
5. PvP не получает неограниченных преимуществ из глобальных запасов игрока.
6. Исходный проект Ncorror/reina-dead-signal не изменяется.
7. Сеть и сервер нагрузочно тестируем до утверждения числа одновременно играющих.

## План начального теста
Godot-оболочка → 3D-сцена → герой и RTS-переключение → производство и экономика → 2 расы → авторитетный матч 1v1 → общая орбитальная карта. CI проверки структуры не является проверкой APK.
