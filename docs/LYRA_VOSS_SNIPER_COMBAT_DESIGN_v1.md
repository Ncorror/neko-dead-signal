# Лира Восс — снайпер-разведчик · RTS боевой дизайн v1

**Решение зафиксировано:** 2026-11-04. **Статус:** согласованная концепция героя и дальности, НЕ реализована в боевом коде. Лира — отдельный управляемый RTS-герой, без ручного TPS/FPS-управления.

## Дальность — обязательная правка +2

| Параметр | Предыдущее предложение | Новое решение |
|---|---:|---:|
| Стандартный снайперский диапазон | 14–16 | **16–18 игровых единиц** |
| Штатная дальность Лиры в будущем конфиге | — | **16** |
| Дальность из подготовленной позиции / Overwatch | — | **18** |
| Обычный эскорт, ориентир для сравнения | 8 | 8 (без изменения) |

Игровая единица — расстояние XZ в сцене Godot. Дальность 18 — максимум *при наличии видимости и прямой линии огня*. Большая дальность винтовки **не снимает** требование обнаружить врага собственными сенсорами, союзником или дроном; цель в тумане войны не становится автоматически видимой.

Числа 16 и 18 — утверждённый ориентир дальности Лиры **для следующей реализации**; фактический баланс урона, HP, прицеливания и перезарядки проверяется на Android. Текущий тестовый `LandingCombatant.weapon_range` по умолчанию равен 5.0 и пока не использует специализацию Лиры; **не считать дальность 16–18 уже работающей**.

## Базовая RTS-механика

- Дальняя точечная поддержка, устранение опасных одиночных целей: офицеров, медиков, снайперов, операторов и поддержки.
- Сильный выстрел с низкой частотой. Ориентир *для тестов*: 1.2 с неподвижного прицеливания, 2.5–3.5 с до следующего выстрела. Это предложения по темпу, не окончательные принятые цифры.
- Если во время прицеливания Лира получает приказ движения, теряет цель или линию огня — накопленный прогресс прицеливания сбрасывается. Она не стреляет на ходу. После перемещения требуется повторно занять позицию.
- Нельзя вести прицельный огонь сквозь препятствия или по невидимой цели. Потерянный контакт запускает логику последней известной позиции, **не магическое знание координат**.
- **Пассивка «Подготовленная позиция» подтверждена пользователем 2026-11-05:** после нахождения без движения на позиции раскрывает дальность **с 16 до 18**, а первый качественно прицельный выстрел с подготовленной позиции получает дополнительную эффективность. Бонус подготовки обнуляется при перемещении. Время подготовки и сила первого усиленного выстрела — параметры баланса (2–3 с лишь кандидат).
- Против массы дешёвых бойцов, ближнего натиска и мобильных противников Лира слабее обычной универсальной пехоты.

## Способности и очередь реализации

| Приоритет | Способность | Игровая функция |
|---|---|---|
| P0 | Снайперская атака | Длительное прицеливание, один точный мощный выстрел, пауза между выстрелами, ограничения укрытиями и видимостью |
| P0 | Подготовленная позиция | +2 к базовой дальности: 16 → 18 при неподвижности; сбрасывается после движения |
| P1 | Метка цели | Раскрытие врага **только по правилам разведки**, выбор приоритета, потенциальный бонус координации отряда |
| P1 | Снайперский выстрел | Усиленная атака по одной важной цели с отдельным восстановлением способности |
| P1 | Разведдрон | Обзор/подсветка врагов по реальным серверным правилам видимости, не сквозь карту |
| P2 | Смена позиции | Короткая тактическая передислокация по RTS-приказу, без FPS-перекатов от джойстика |
| P2 | Наблюдение / Overwatch | Приоритетный огонь в заданном секторе, требует позиции и знания цели; дальность не выше 18 |

**Механика усиления первого подготовленного выстрела утверждена**, но величины усиления, критического урона и бронепробития пока не утверждены — **не вводить случайные +50% и ваншоты как готовый баланс**.

## Механика боя: конечный автомат

```
MOVE -> POSITIONING -> AIMING (candidate 1.2s) -> SHOT
  -> RECOVERY (candidate 2.5–3.5s) -> AIMING
                         |
                         + movement / lost sight / blocked LOS -> AIM RESET
```

- Все приказы выполняются существующей RTS-очередью `move / attack / stop`, не создавая отдельной схемы ручного управления.
- В PvP/сетевом режиме решение о видимости, позиционировании, попадании и уроне принимает сервер. Клиент анимирует результат, а не решает исход.
- Атака должна логировать `sniper_aim_started`, `sniper_aim_canceled`, `sniper_shot`, `sniper_range_bonus_on/off`, `sniper_los_blocked` **только в debug**.

## Анимации / VFX для будущей 3D-модели

**P0:** Idle с винтовкой, Walk/Run (оружие опущено), переход в устойчивую стойку, прицеливание стоя, выстрел с отдачей, перезарядка, Hit, Death.  
**P1:** прицеливание с колена, стрельба с колена, переход стойка↔колено, развёртывание/складывание разведдрона, визуальная метка цели.  
**P2:** осторожное перемещение, подготовленная позиция, короткая смена укрытия, специальная способность.

Анимации не должны задавать физическую дальность, урон, серверный тайминг или скорость передвижения. При выборе Meshy-клипов сначала проверять качество снайперского хвата, расстановку кистей и поворот корпуса; универсальный `Attack` не гарантирует корректную стрельбу из длинной винтовки. Исходный модельный референс: Лира Восс, короткие серебристые волосы, розово-чёрная лёгкая экипировка, кошачьи эмблемы. Оружие — **снайперская винтовка**, не штурмовой автомат.

## Проверки перед выпуском механики

1. Дистанции 15.9 / 16.0 / 16.1 и 17.9 / 18.0 / 18.1: обычная и подготовленная позиция.
2. На 18 при открытом секторе и видимости Лира стреляет, на 18.1 — не стреляет.
3. Неподвижная Лира получает подготовку; перемещение обнуляет прицел и бонус.
4. За препятствием в зоне действия выстрел заблокирован.
5. Цель вне тумана войны недоступна для адресного приказа, если её не обнаружил союзник/дрон.
6. При смене цели и отмене приказа не остаётся «готового» выстрела.
7. Не ломаются очереди RTS-приказов, мини-карта, камера и баланс остальных командиров.
8. На Android проверить дальность, упреждение, удобство целеуказания и стоимость расчётов.

**Текущие файлы-прототипы:** `client/scripts/combatant.gd` и `client/scripts/operation.gd`. При реализации потребуется отдельный профиль Лиры (и явное различение дальности винтовки и радиуса обзора). В этом документальном коммите игровой код не меняем.
