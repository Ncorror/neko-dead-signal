# REINA: DEAD SIGNAL — RTS

**СТАТУС: PRE-ALPHA / Android / Godot 4.7.2.** Отдельная приватная научно-фантастическая онлайн-стратегия; не полноценный мультиплеер.

## Зафиксированная игровая концепция

- **Только RTS**: изометрическая камера, выделение юнитов и группы, тактические приказы и способности. **Нет** прямого управления героиней, джойстика и FPS/TPS-режима.
- На командном корабле игрок выбирает расу и своего командира; выбранная героиня **сразу появляется в начальном десанте** и управляется как отдельный юнит.
- Люди и Саари имеют отдельные флоты, командиров, армии, здания и технологические ветки.
- Ресурсы, туман войны, контейнеры, производство юнитов и наземных машин — целевые системы; онлайн-боевые расчёты будут авторитетными на сервере.
- Оригинальные аниме-героини: Амина, Рэйна, Лира Восс и Мира Кейд; 2D-портреты отдельно от анимированных 3D-моделей. Кошачьи эмблемы утверждены.
- Орбитальный мир, кланы, PvPvE, дипломатия и «Легенды мира» входят в долгосрочный план.

## Состояние реализации

| Есть | Ещё нет |
|---|---|
| Экран выбора фракции и офицера | Подключённых окончательных моделей Meshy |
| Локальная высадка с двумя бойцами, приказами движения и атаки, стражем и тремя контейнерами | Сетевых матчей, авторитетной симуляции |
| Сборка Android ARM64 debug на венском Runner | Производства, командирских навыков, мобильного ИИ и тумана войны |
| `/healthz` локального служебного API | Публичного готового игрового сервера |

**Важно:** `reina-rts-bootstrap.service` на венском VPS — только health service, не мультиплеерный бэкенд. Старый репозиторий `Ncorror/reina-dead-signal` был удалён отдельно; его не воссоздаём.

## Первая высадка · 0.0.2

На корабле выбери фракцию и командира, затем нажми «Начать высадку». На поверхности нажми «Все», затем коснись оранжевого стража. Бойцы обойдут препятствия, сблизятся и откроют огонь. Страж обстреливает ближайшую видимую цель. Приказ в точку сменяет атаку, «Стоп» действует на выделенных бойцов.

Для победы уничтожь стража и проведи любого уцелевшего бойца к трём золотым контейнерам. Гибель обоих завершает высадку поражением. «На корабль» показывает итог и сохраняет выбор офицера до выхода из игры. Следующая высадка начинается заново.

## Структура

- `client/` — Godot Android, орбитальный штаб и локальный RTS-прототип.
- `server/` — локальный health stub и тесты; игровой backend впереди.
- `assets/art/commanders-v1/` — каталог/манифест графики. **Индекс концептов в GitHub; PNG/GLB в отдельном ZIP для загрузки через Termux. Не утверждать, что бинарные исходники уже загружены, пока они не появятся в каталоге.**
- `docs/ONLINE_WORLD_GDD_v0.2.md` — **актуальный** документ с чистой RTS; версия 0.1 историческая.
- `docs/DECISIONS.md` — утверждённые решения.
- `docs/COMMANDER_ROSTER_AND_ANIMATIONS_v1.md` — командиры.
- `docs/ANIMATION_REQUIREMENTS_RTS.md` — проверенная библиотека и приоритеты анимаций Meshy.
- `docs/MESHY_PIPELINE.md` — процесс получения 3D и GLB.
- `docs/ARCHITECTURE.md`, `docs/ROADMAP.md` — техархитектура и этапы.
- `.github/workflows/vienna-rts-android.yml` — сборка Android на `reina-rts-ci`.

## Сборка

Android SDK и Godot 4.7.2 установлены на приватном венском Runner. Отдельные ветки проверяются CI до интеграции в `main`. APK от GitHub Actions всё равно требует реальной проверки на Android.

**Безопасность:** не отправлять в репозиторий токены, подписи, `.env` и секреты. Не удалять рабочие функции без отдельного подтверждения.
