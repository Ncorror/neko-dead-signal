# NEKO: DEAD SIGNAL — server stub (legacy runtime names)

**Текущая реализация:** `control_api.py` — отдельная служба только для `/healthz` (200), `/readyz` намеренно возвращает 503, пока нет реального игрового сервера. Unit-тесты: `test_control_api.py`. По коду и конфигурации службы она предназначена слушать только `127.0.0.1:18777` на венском VPS; живое состояние службы в репозиторном аудите 2026-11-04 не перепроверялось.

**Не реализовано:** авторитетные матчи, команды `move/attack/ability/interact/stop`, серверный тик, экономика, туман войны, matchmaking, постоянный мир, аутентификация. Не открывать этот API в Интернет и не объявлять его готовой онлайн-игрой.

Целевая архитектура и инварианты: `docs/ARCHITECTURE.md`, `docs/DEAD_SIGNAL_EARTH_GDD_v0.4.md`.
