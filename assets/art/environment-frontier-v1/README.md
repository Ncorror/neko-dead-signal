# Frontier v1 · просмотр геометрии

[Контактный лист моделей](contact_sheet.png) отрисован из тех же исходных вершин, которые экспортируются в GLB. Отдельные модели показаны в нормализованном масштабе для проверки формы, цвета и пересечений. **Это не игровой скриншот и не измерение Android FPS.**

Генератор: [build_environment_kit.py](../../../tools/build_environment_kit.py). Технический рендерер: [render_environment_kit.py](../../../tools/render_environment_kit.py). Модели и контрольные суммы: [пакет GLB](../../../client/assets/environment/frontier_v1/README.md).

Первый художественный проход сохраняет холодный sci-fi стиль с небольшими светлыми и охристыми акцентами. Вид под игровой камерой и производительность проверяются в APK; пользовательские референсы героинь и утверждённая Female Base v3 к этому пакету не относятся.
